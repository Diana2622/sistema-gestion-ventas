# Código Fuente

Esta carpeta contiene el código fuente del Sistema de Gestión de Ventas.

## Módulos principales

- Clientes
- Proveedores
- Usuarios
- Ventas
- Pagos
- Autenticación

## Control de cambios

Las modificaciones al código deberán realizarse mediante ramas de desarrollo y posteriormente integrarse a la rama principal después de su revisión.
