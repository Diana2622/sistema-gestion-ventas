# Módulo de Autenticación

Este módulo corresponde a la implementación de autenticación en dos factores (2FA), solicitada mediante la Solicitud de Cambio CR-001.

## Funcionalidad

- Autenticación mediante usuario y contraseña.
- Segundo factor de autenticación.
- Validación del código de seguridad.
- Protección adicional para el acceso al sistema.

## Solicitud relacionada

**CR-001:** Implementación de autenticación en dos factores (2FA).
