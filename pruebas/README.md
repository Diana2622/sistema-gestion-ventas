# Pruebas del Sistema

Esta carpeta contiene los casos y resultados de las pruebas realizadas al Sistema de Gestión de Ventas.

## Tipos de pruebas

- Pruebas funcionales.
- Pruebas de integración.
- Pruebas de autenticación.
- Pruebas de pagos.

## Control de pruebas

Cada prueba debe registrar su objetivo, procedimiento, resultado esperado, resultado obtenido y estado.

## Cambios

Cuando se agregue una nueva funcionalidad, se deben crear o actualizar las pruebas correspondientes.
