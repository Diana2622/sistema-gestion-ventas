# Modelado del Sistema

Esta carpeta contiene los modelos y diagramas UML utilizados para representar el Sistema de Gestión de Ventas.

## Diagramas

- Diagrama de casos de uso.
- Diagrama de clases.
- Modelo de dominio.

## Propósito

Los diagramas permiten representar de manera visual la estructura, comportamiento y relaciones principales del sistema.
