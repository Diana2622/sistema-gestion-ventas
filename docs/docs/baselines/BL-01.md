# Baseline BL-01

## Identificación

**Código:** BL-01  
**Nombre:** Baseline inicial del Sistema de Gestión de Ventas  
**Versión:** 1.0  
**Fecha:** 02/10/2026  
**Estado:** Aprobada

## Descripción

La Baseline BL-01 representa la versión inicial aprobada del Sistema de Gestión de Ventas antes de realizar modificaciones solicitadas por el cliente.

## Elementos incluidos

- Documento de requisitos.
- Diagrama de casos de uso.
- Modelo de dominio.
- Diagrama de clases.

## Criterios de revisión

- Los requisitos son claros y no presentan contradicciones.
- Los casos de uso corresponden con los requisitos.
- El modelo de dominio representa correctamente los conceptos principales.
- El diagrama de clases presenta relaciones coherentes.
- Los documentos tienen identificada su versión.
- Los errores encontrados durante la revisión fueron corregidos.
- Los elementos fueron revisados por el equipo.
- La versión inicial fue aprobada.

## Estado

La Baseline BL-01 queda establecida como punto de referencia para controlar los cambios posteriores.

Cualquier modificación posterior deberá realizarse mediante una Solicitud de Cambio (CR).
