# Documento de Requisitos

Este archivo contiene los requisitos del Sistema de Gestión de Ventas.

## Requisitos funcionales

- Gestión de clientes.
- Gestión de proveedores.
- Gestión de usuarios.
- Gestión de ventas.
- Registro y consulta de información.

## Requisitos no funcionales

- Seguridad.
- Disponibilidad.
- Facilidad de uso.
- Mantenibilidad.
